# Скачать ZIP и запустить

1. Войдите в GitHub под аккаунтом, которому предоставлен доступ к репозиторию.
2. Откройте https://github.com/vadimsafronov21-lgtm/russkie-bliny и выберите **Code → Download ZIP**.
3. Полностью распакуйте архив в обычную папку, например `C:\Projects\russkie-bliny-main`. Запускать файлы прямо внутри ZIP нельзя. Папки `src`, `config` и `data` должны находиться рядом со `start.bat`.
4. Нужны **Windows 10/11 x64** и установленный **Python 3.11, 3.12 или 3.13 x64**. Если Python отсутствует, установите его с https://www.python.org/downloads/windows/ и включите **Add python.exe to PATH**.
5. Дважды щёлкните **start.bat**. При первом запуске он создаст `.venv` и установит библиотеки в папку проекта. Нужен интернет; установка может занять несколько минут. Не закрывайте окно до завершения.
6. В приложении нажмите **«Открыть учебный сценарий»**. База SQLite создаётся автоматически. Выберите вкладку «Закупки» и строку ингредиента, чтобы увидеть объяснение.

Следующие запуски: снова откройте `start.bat`. Если установленное окружение не менялось, повторного скачивания библиотек не будет.

## Что есть в архиве

Исходники, конфигурация, CSV-шаблоны, шесть наборов синтетических данных, исходный и выполненный ноутбуки, тесты, документация и готовые примеры отчётов в `examples/reports`. Вся логика работает локально. Для обычного запуска Git не нужен.

Скопированное чужое виртуальное окружение не является переносимой установкой Python: поэтому библиотеки устанавливаются автоматически для вашего компьютера. Это исходный проект с установщиком, **не автономный EXE**. Полностью офлайн-первый запуск и запуск без установленного Python в этот ZIP не входят.

## Если появилась ошибка

- «Не найден Python»: установите подходящий 64-битный Python и повторите запуск.
- Ошибка скачивания библиотек: проверьте интернет, прокси/доступ к PyPI и снова запустите `start.bat`.
- После распаковки в другую папку установите окружение заново в новой папке; `.venv` из старой папки копировать не нужно.
- Сохраните текст ошибки из окна. Не удаляйте CSV и конфигурацию.

Для аналитиков: откройте PowerShell в папке распакованного проекта и выполните `python launch.py --setup-only --dev`. Это добавит pytest и Jupyter. Затем используйте команды из README.

Для установки без открытия окна: `start.bat --setup-only`. Для автоматической проверки: `start.bat --smoke-test`.
