# Проверка первого рабочего среза

Дата: 16 октября 2026 года. Окружение: Windows, Python 3.13, Node.js 24, локальная SQLite. Все записи — синтетические. Реальная 1С не участвовала.

| Проверка | Фактический результат |
|---|---|
| Серверные тесты `pytest -q` | **16 passed**, 44,23 с; одна deprecation-подсказка Starlette о будущем переходе тестового клиента с httpx на httpx2 |
| Проверка кода Ruff | **All checks passed** |
| Все три миграции на пустой SQLite | Применились; `alembic check` не обнаружил расхождений со схемой моделей |
| Миграции на существующей demo-БД | Применились с сохранением истории; nullable-время известности не подменяет неизвестную историю |
| TypeScript и Vite build | Успешно; собрана версия интерфейса с обработкой ошибок в диалогах и пропусков данных |
| Playwright / Edge | **2 passed**, 19,4 с; создание заявки, принятие, накладная, отправка, частичная и окончательная приёмка; аналитика и прогноз |
| Мобильный интерфейс | Проверен viewport 390×844; документ не выходит за ширину экрана, широкие таблицы прокручиваются внутри своих блоков |
| Ошибки JavaScript в основном браузерном сценарии | Не обнаружены (`pageerror`) |
| Worker | Созданы 16 `.eml`-писем в локальном sink; сетевой email не использовался |
| SQLite backup и восстановление | Новая восстановленная БД: целостность OK, внешние ключи OK, совпали количество строк и хеши содержимого **18 таблиц**, включая Alembic |
| PostgreSQL / Docker Compose | **Не запускались**: на этом ПК нет Docker/PostgreSQL. Подготовлены конфигурация и CI, но результаты их исполнения не заявляются |

Серверные сценарии покрывают: расход 300 г для 10 порций; повтор события/команды и конфликт payload; параллельный повтор; историю рецептур; отмену до приготовления и возврат готового блюда без возврата сырья; приёмку только фактического количества; запрет переприёмки; повтор приёмки; наличие поставки в расчёте; дедупликацию одинаковых активных заявок; версию документа; резерв склада и откат неуспешной транзакции; отрицательный остаток; изоляцию точек/ролей; CSRF; недоступность SMTP без блокировки заявок; временное разделение baseline; исключение поздних сведений; пропуск данных, отличный от нуля; отсутствие паролей в API; миграции на пустой БД.
