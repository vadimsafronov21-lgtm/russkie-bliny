# Русские блины — Git-версия

- Эта папка содержит Git-версию приложения «Русские блины».
- Для локального проекта общая память находится уровнем выше: сначала явно прочитать `../AGENTS.md`.
- Затем читать нужные файлы памяти из родительской папки по условиям общего паспорта: `to-do.md`, `gotchas.md`, `bugs.md`, `decisions.md`, `style.md`.
- Ссылки не загружают содержимое автоматически: прочитать файлы инструментом чтения.
- Выполнять команды из этой папки; перед изменением кода проверить Git-статус и сохранить чужие незавершённые изменения.
- README.md, DATA_FORMAT.md, DESIGN.md и PILOT.md этой версии уточняют её поведение.
- При отсутствии родительской памяти (например, после отдельного клонирования) не придумывать её содержимое: использовать локальные документы и сообщить, что комплект памяти не перенесён.
- Обновлять общий комплект памяти после существенных задач; не создавать здесь расходящуюся вторую копию.
